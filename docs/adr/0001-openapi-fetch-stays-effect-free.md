# openapi-fetch stays Effect-free internally

`@shipworthy/openapi-fetch` is implemented with plain async TypeScript, not Effect, despite the repository-wide preference for Effect. We tried bundling a private Effect runtime behind the unchanged Promise interface (branch `lott/effect-internal-fetch`). It grew the React Native bundle 2.8× in Hermes bytecode (50.7 KB → 143.8 KB) and added a second build step. It also needed adapter helpers to reproduce native Promise semantics. Effect's runtime capabilities (retries, interruption-based cancellation, deduplication, caching) duplicate TanStack Query, which is how the client is typically consumed via `@shipworthy/openapi-tanstack-query`. Revisit only if the client itself must own retries, timeouts, rate limiting, or cancellation for direct (non-TanStack) callers.
